# Security policy

## Get the mod only from here

The only official source of **Jagged Alliance 2 UINT-16** mod is the [Releases](../../releases) page of this repository.

- Before running `ja2u16.exe`, scan the archive with an online multi-engine scanner.
- Scanners to use: [MetaDefender](https://metadefender.com/), [VirusTotal](https://www.virustotal.com/), [Hybrid Analysis](https://www.hybrid-analysis.com/), [Jotti's malware scan](https://virusscan.jotti.org/).
- The mod is **free**. If someone sold it to you, asked you to pay for it or sent it through another site, treat that copy as unsafe and delete it.

## Supported versions

| Version | Supported |
|---|---|
| [Latest release](../../releases/latest) | ✅ |
| Older releases | ❌ |

Only the latest release gets fixes. Please update before reporting a problem.

## Reporting a vulnerability

Please report security problems **privately**, not in a public issue:

- a flaw in the mod that could harm a user's computer or files (e.g. through a crafted save or a mod archive);
- a fake or modified copy of the mod being spread somewhere.

Use **Security → Report a vulnerability** in this repository. If that button is not available, open an [issue](../../issues) titled **Security: contact request** without any details, and the maintainer will contact you.

Include what is affected, how to reproduce it and the mod version. You will get an answer as soon as possible; fixed problems are credited in the release notes unless you prefer to stay anonymous.

## Your game files

The mod runs from its own `Data-UINT16` folder and its own `ja2u16.exe` and writes its own settings and saves; the stock game files are not changed. This is not a vulnerability.
